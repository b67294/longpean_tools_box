# 接口文档

## 本地 ComfyUI

基础地址：`http://127.0.0.1:6070`

官方参考：<https://docs.comfy.org/development/comfyui-server/comms_routes>

### Agent 调用原则

只记住最重要的 3 个接口：

1. `POST /prompt`：下发生成任务。
2. `GET /history/{prompt_id}`：查询任务结果。
3. `GET /view`：读取生成图片。

标准流程：

1. 准备 ComfyUI API 格式工作流 JSON。
2. 调用 `/prompt` 下发任务。
3. 从返回结果中保存 `prompt_id`。
4. 轮询 `/history/{prompt_id}`，直到任务完成。
5. 从 `outputs` 中取图片的 `filename`、`subfolder`、`type`。
6. 调用 `/view` 获取最终图片。

### 1. 下发任务

`POST http://127.0.0.1:6070/prompt`

用途：把 ComfyUI API 格式工作流提交到执行队列。

请求体关键字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `prompt` | 是 | ComfyUI API 格式工作流，不是普通 UI 工作流。 |
| `client_id` | 建议 | 客户端 ID，便于追踪任务。 |
| `extra_data` | 否 | 附加业务数据。 |

成功时关注：

| 字段 | 说明 |
| --- | --- |
| `prompt_id` | 后续查询结果必须使用的任务 ID。 |
| `number` | 队列编号。 |
| `node_errors` | 节点校验错误；为空通常表示提交成功。 |

失败时关注：

| 字段 | 说明 |
| --- | --- |
| `error` | 总体错误信息。 |
| `node_errors` | 具体节点错误，优先检查这里。 |

### 2. 查询生成结果

`GET http://127.0.0.1:6070/history/{prompt_id}`

用途：根据 `prompt_id` 查询任务执行状态和输出文件。

重点读取：

| 字段 | 说明 |
| --- | --- |
| `status.completed` | 是否完成。 |
| `status.status_str` | 状态文本，常见成功值为 `success`。 |
| `outputs` | 输出节点结果。 |
| `outputs.*.images` | 图片结果列表。 |

图片结果关键字段：

| 字段 | 说明 |
| --- | --- |
| `filename` | 图片文件名。 |
| `subfolder` | 图片所在子目录，可能为空。 |
| `type` | 文件类型，常见为 `output`。 |

注意：

- 如果还没完成，`outputs` 可能为空或不完整。
- Agent 应轮询此接口，直到 `status.completed` 为 `true`。
- 查询图片时不要猜文件名，应从 `history` 返回值中读取。

### 3. 读取生成图片

`GET http://127.0.0.1:6070/view`

用途：根据 `history` 返回的文件信息读取图片。

查询参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `filename` | 是 | 来自 `outputs.*.images[].filename`。 |
| `type` | 建议 | 来自 `outputs.*.images[].type`，通常是 `output`。 |
| `subfolder` | 否 | 来自 `outputs.*.images[].subfolder`，为空也要按空值处理。 |

最终图片地址格式：

`http://127.0.0.1:6070/view?filename={filename}&type={type}&subfolder={subfolder}`

### 可选：实时进度

`ws://127.0.0.1:6070/ws`

用途：需要实时进度时使用；只查询最终结果时可以不用。

常见消息：

| 类型 | 说明 |
| --- | --- |
| `status` | 队列或系统状态。 |
| `execution_start` | 工作流开始执行。 |
| `executing` | 当前执行节点。 |
| `progress` | 节点内部进度。 |
| `executed` | 节点执行完成。 |
| `execution_cached` | 使用缓存结果。 |

### Agent 注意事项

- 所有接口默认使用本地端口 `6070`。
- 下发任务必须使用 ComfyUI API 格式工作流。
- 最核心的任务 ID 是 `/prompt` 返回的 `prompt_id`。
- 最核心的结果字段是 `/history/{prompt_id}` 返回的 `outputs`。
- 最终图片必须通过 `/view` 读取。
- 如果接口失败，优先检查 `node_errors`。

## Longpean 图云上传

基础接口：`POST https://stpic.longpean.com/picture/upLoadQiNiu`

用途：把本地图片上传到 Longpean 远端图云，拿到可访问的图片 URL。

来源：

- `tools/upload_raw_to_longpean.py`
- `assets/longpean-raw-urls.json`

### Agent 调用原则

只关注 2 件事：

1. 请求体传图片字节和文件名。
2. 响应里的 `data` 就是远端图片 URL。

### 请求体关键字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `picBytes` | 是 | 图片二进制内容转成的整数数组。 |
| `fileName` | 是 | 上传后的文件名，建议使用 UUID 加原图片扩展名。 |

### 成功时关注

| 字段 | 说明 |
| --- | --- |
| `data` | 远端图片 URL，通常是 `https://pspk.longpean.com/{fileName}`。 |

### Agent 注意事项

- 上传成功后，把本地路径、`fileName`、远端 `url` 记录到 manifest，当前项目使用 `assets/longpean-raw-urls.json`。
- 后续 Banana 生成任务的 `refUrl` 通常使用这里返回的 `data`。
- `https://pspk.longpean.com/*.png` 是静态图片地址，不是接口。

## Longpean Banana 图片生成

基础接口：`POST https://test-aigc.longpean.com/drawByAi/createWrapperTextToBananaImageTask`

用途：创建 Longpean Banana 文生图/参考图生成任务。

来源：

- `tools/create_banana_image_task.py`
- `tools/longpean-banana.config.json`

### Agent 调用原则

只关注 3 件事：

1. `taskContent` 放生成提示词。
2. `refUrl` 放参考图 URL，通常来自 Longpean 图云上传接口。
3. 其它固定业务字段从 `tools/longpean-banana.config.json` 读取。

### 请求体关键字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `taskContent` | 是 | 生成任务提示词，当前脚本默认压成单行。 |
| `refUrl` | 是 | 参考图 URL，通常是 `https://pspk.longpean.com/*.png`。 |
| `resolutionRatio` | 是 | 业务尺寸描述，当前配置为 `500×43cm`。 |
| `resolutionRatioExt` | 是 | 比例字段，当前配置为 `1:1`。 |
| `isHd` | 是 | 是否高清。 |
| `genQuantity` | 是 | 生成数量。 |
| `sourceOp` | 是 | 业务来源字段。 |
| `genType` | 是 | 生成类型字段。 |
| `styleId` | 是 | 风格 ID。 |
| `width` | 是 | 输出宽度。 |
| `high` | 是 | 输出高度；字段名是 `high`，不是 `height`。 |
| `bizKey` | 是 | 业务 key。 |
| `createdBy` | 是 | 创建人 ID。 |
| `createdByName` | 是 | 创建人名称。 |

### 当前项目默认配置

| 字段 | 当前值 |
| --- | --- |
| `apiUrl` | `https://test-aigc.longpean.com/drawByAi/createWrapperTextToBananaImageTask` |
| `resolutionRatio` | `500×43cm` |
| `resolutionRatioExt` | `1:1` |
| `isHd` | `false` |
| `genQuantity` | `1` |
| `sourceOp` | `15` |
| `genType` | `98` |
| `styleId` | `41` |
| `width` | `1024` |
| `high` | `1024` |
| `bizKey` | `WRAPPER_TEXT_T0_FULL_IMG202503180007934` |
| `createdBy` | `1639` |
| `createdByName` | `zsy` |

### 成功时关注

当前目录只确认了“创建任务”接口，未发现配套的“查询任务结果”接口。

Agent 调用后应优先检查创建接口响应里是否直接包含以下字段：

| 可能字段 | 说明 |
| --- | --- |
| `data` | 可能是任务信息、任务 ID，或直接结果。 |
| `taskId` / `id` | 可能是后续查询结果需要的任务 ID。 |
| `url` / `imageUrl` / `imgUrl` | 如果响应里直接出现，可能就是生成结果图片 URL。 |

### Agent 注意事项

- 这是 `test-aigc.longpean.com` 测试环境接口。
- 当前脚本只负责创建任务并保存响应，不包含轮询结果的逻辑。
- 如果创建接口响应没有直接返回结果图片 URL，需要补充公司侧的任务查询接口。
- 结果图片 URL 是否能直接拿到，取决于创建接口响应；当前本地文件无法确认。
