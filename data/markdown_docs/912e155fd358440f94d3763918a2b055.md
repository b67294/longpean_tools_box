# OpenAI 兼容接口 · Chat Completions

> 对应代码：`browserplugin/plugin-server` · `com.lp.plugin.controller.OpenAiCompatController`
> YApi：http://172.16.105.86:3000/project/254/interface/api/38040

## 1. 概述

对外暴露一个与 OpenAI `/v1/chat/completions` 协议兼容的统一入口，按请求中的 `model`
**前缀自动路由**到对应的 AI 供应商（OpenAI / Claude / Gemini / DeepSeek / 豆包 / 通义千问 /
本地 gpt-image-2），并**透传供应商原始 JSON 响应，不做格式转换**。

- 第三方客户用 `Authorization: Bearer sk-lp-{clientId}-{随机}` 鉴权。
- 上游真实 API Key 由服务端从 Redis VIP 配置（默认 `vipCode=longpean-agent`）注入，客户无需感知。
- **不支持流式**（`stream=true` 直接报错）。
- 请求/响应、Token 用量、调用客户、耗时等异步落库（`OpenAiCompatRequestLog`、
  `t_chatgpt_operator_question_log`），base64 大图数据写库前会截断。

---

## 2. 基本信息

| 项           | 值                                      |
| ------------ | --------------------------------------- |
| 接口路径     | `POST /v1/chat/completions`             |
| Content-Type | `application/json`                      |
| 鉴权         | `Authorization: Bearer <token>`（必填） |
| 是否支持流式 | 否                                      |

---

## 3. 鉴权

请求头必须携带：

```
Authorization: Bearer sk-lp-{clientId}-{16位随机串}
```

- token 由内部颁发接口为某个 `clientId` 生成并保存在 Redis；服务端用 token 反查 `clientId`。
- 缺失 / 格式不对 / 查不到 `clientId` → **401**，返回标准 OpenAI 错误体（`code=invalid_api_key`）。
- `Bearer ` 前缀大小写不敏感。

---

## 4. 请求参数（Body）

| 字段            | 类型    | 必填 | 说明                                                         |
| --------------- | ------- | ---- | ------------------------------------------------------------ |
| `model`         | string  | 是   | 模型名，决定路由的供应商。见「模型路由表」。空 → 400。       |
| `messages`      | array   | 是   | 对话消息数组，不能为空。空/缺失 → 400。                      |
| `temperature`   | number  | 否   | 采样温度，透传给供应商。                                     |
| `max_tokens`    | integer | 否   | 最大生成 token 数，透传。                                    |
| `stream`        | boolean | 否   | 仅支持 `false`；传 `true` → 400（`code=streaming_not_supported`）。 |
| `gemini_config` | object  | 否   | Gemini 专用配置，仅 `gemini-*` 模型生效。见 4.3。            |
| `image2_config` | object  | 否   | gpt-image-2 专用配置，仅 `model=gpt-image-2` 生效。见 4.4。  |

### 4.1 message 对象

| 字段      | 类型            | 说明                                            |
| --------- | --------------- | ----------------------------------------------- |
| `role`    | string          | `system` / `user` / `assistant`                 |
| `content` | string \| array | 纯文本时为字符串；多模态时为 `ContentPart` 数组 |

### 4.2 content part 对象（多模态）

| 字段        | 类型   | 说明                                                 |
| ----------- | ------ | ---------------------------------------------------- |
| `type`      | string | `text` 或 `image_url`                                |
| `text`      | string | `type=text` 时的文本                                 |
| `image_url` | object | `type=image_url` 时的图片，结构为 `{ "url": "..." }` |

`image_url.url` 支持：HTTP(S) URL，或 `data:image/xxx;base64,...` 内联 base64。

### 4.3 gemini_config（Gemini 专用）

| 字段                 | 类型     | 说明                                         |
| -------------------- | -------- | -------------------------------------------- |
| `responseModalities` | string[] | 响应模态，如 `["IMAGE"]`、`["TEXT","IMAGE"]` |
| `imageConfig`        | object   | 图片生成配置                                 |

### 4.4 image2_config（gpt-image-2 专用）——非必填

| 字段            | 类型    | 说明                                                         |
| --------------- | ------- | ------------------------------------------------------------ |
| `size`          | string  | 图片尺寸，如 `1024x1024`、`1024x1536`、`auto`；缺省 `1024x1024` |
| `template_code` | string  | 模板编码                                                     |
| `operator_id`   | integer | 操作人 ID                                                    |
| `operator_name` | string  | 操作人名称                                                   |

---

## 5. 模型路由表

服务端按 `model` 匹配供应商适配器（命中第一个 `supports` 的适配器）：

| 供应商           | 匹配规则（model）                         | 备注                                                |
| ---------------- | ----------------------------------------- | --------------------------------------------------- |
| OpenAI           | `gpt-` 开头，且**不是** `gpt-image-` 开头 |                                                     |
| Claude           | `claude-` 开头                            | 响应透传，`usage` 为 `input_tokens`/`output_tokens` |
| Gemini           | `gemini-` 开头                            | 含 `image` 的模型走多账号负载均衡，不取 VIP key     |
| DeepSeek         | `deepseek-` 开头                          |                                                     |
| 豆包 DouBao      | `doubao-` 开头 或 `ep-` 开头              |                                                     |
| 通义千问 Qwen    | `qwen-` 开头                              | 暂不支持                                            |
| 本地 gpt-image-2 | 精确等于 `gpt-image-2`                    | 路由到本地生图服务，不调外部 key                    |

匹配不到任何供应商 → **404**（`code=model_not_found`）。

---

## 6. 响应

成功时**原样透传供应商返回的 JSON**（`Content-Type: application/json`）。
OpenAI 标准对话响应结构示意（不同供应商字段可能不同，如 Claude/Gemini 为各自原生结构）：

| 字段      | 类型   | 说明                                                         |
| --------- | ------ | ------------------------------------------------------------ |
| `id`      | string | 响应 ID                                                      |
| `object`  | string | 固定 `chat.completion`                                       |
| `created` | long   | Unix 时间戳（秒）                                            |
| `model`   | string | 模型名                                                       |
| `choices` | array  | 候选回复；元素含 `index` / `message{role,content}` / `finish_reason` |
| `usage`   | object | `prompt_tokens` / `completion_tokens` / `total_tokens`       |

---

## 7. 错误码

错误统一返回 OpenAI 标准错误体：

```json
{
  "error": {
    "message": "错误描述",
    "type": "invalid_request_error",
    "param": null,
    "code": "错误码"
  }
}
```

| HTTP | type                    | code                      | 触发场景                                          |
| ---- | ----------------------- | ------------------------- | ------------------------------------------------- |
| 401  | `invalid_request_error` | `invalid_api_key`         | 鉴权失败（无/错/无效 token）                      |
| 400  | `invalid_request_error` | `invalid_request`         | `model`/`messages` 缺失等参数错误                 |
| 400  | `invalid_request_error` | `streaming_not_supported` | `stream=true`                                     |
| 404  | `invalid_request_error` | `model_not_found`         | 无匹配供应商的 model                              |
| 502  | `server_error`          | `upstream_error`          | 上游供应商调用异常                                |
| 504  | `server_error`          | `timeout`                 | 上游超时（默认 `openai.compat.timeout=600000ms`） |
| 500  | `server_error`          | `internal_error`          | 服务内部异常                                      |

## 8. 请求示例

### 8.1 纯文本（OpenAI / 通用）

```bash
curl -X POST 'https://<host>/v1/chat/completions' \
  -H 'Authorization: Bearer <LONGPEAN_CLIENT_KEY>' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "gpt-4o",
    "messages": [
      { "role": "user", "content": "你好，介绍一下你自己" }
    ],
    "temperature": 0.7,
    "max_tokens": 512
  }'
```

### 8.2 多模态（图片 + 文本）

```json
{
  "model": "gpt-4o",
  "messages": [
    {
      "role": "user",
      "content": [
        { "type": "text", "text": "这张图里是什么？" },
        { "type": "image_url", "image_url": { "url": "https://example.com/a.png" } }
      ]
    }
  ]
}
```

### 8.3 本地 gpt-image-2 生图

```json
{
  "model": "gpt-image-2",
  "messages": [
    { "role": "user", "content": "一只在草地上奔跑的柯基" }
  ],
  "image2_config": {
    "size": "1024x1024",
    "template_code": "TPL_001",
    "operator_id": 1001,
    "operator_name": "张三"
  }
}
```

### 8.4 Gemini 生图

```json
{
  "model": "gemini-2.5-flash-image",
  "messages": [
    { "role": "user", "content": "把这张图改成卡通风格" }
  ],
  "gemini_config": {
    "responseModalities": ["IMAGE"]
  }
}
```

## 9. 行为说明

- **透传不转换**：成功响应直接返回供应商原始 JSON，结构以各供应商为准。
- **日志异步落库**：请求体/响应体写库前对 `data:image/...;base64,...` 及 Gemini `inlineData`
  做占位替换并截断到 2000 字符，避免大图占满日志表。
- **Token 用量解析**：OpenAI 标准取 `usage.{prompt,completion,total}_tokens`；
  Claude 取 `usage.{input,output}_tokens`；Gemini 取顶层 `usageMetadata.*`。
- **超时**：默认 600s（`openai.compat.timeout`），可在 Nacos 配置覆盖。
