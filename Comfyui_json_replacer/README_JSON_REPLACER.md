# ComfyUI JSON 字段替换工具 - 使用说明

## 功能介绍

这个工具用于快速、便捷地替换 ComfyUI 工作流导出 JSON 中的指定节点字段值。适用于需要批量修改工作流参数的场景。

## 界面布局

### 左侧面板 - 替换规则设置
- **输入格式**：`节点号,输入字段,替换内容`
- **示例**：
  ```
  22,url,#{image}
  15,seed,123456
  8,text,生成的提示词
  ```
- **按钮功能**：
  - **清空规则**：清除所有输入的规则
  - **验证规则**：检查规则格式是否正确

### 右侧面板 - JSON 编辑器
- **粘贴或编辑** ComfyUI 导出的工作流 JSON
- **按钮功能**：
  - **加载 JSON**：打开帮助信息
  - **验证 JSON**：检查 JSON 格式是否正确
  - **格式化 JSON**：美化 JSON 显示（缩进和换行）
  - **执行替换**：按照左侧规则替换 JSON 内容
  - **清空 JSON**：清除 JSON 内容

### 下方面板 - 替换日志
- 显示每次替换操作的详细信息：
  - 替换的节点号和节点名称（class_type）
  - 替换的字段名
  - 替换前后的值
  - 操作成功/失败的状态

## 使用步骤

### 1. 准备工作流 JSON
从 ComfyUI 导出工作流，获得 API 格式的 JSON：
- 在 ComfyUI 中，右键点击导出 → 导出 API 格式
- 或使用 Ctrl+Shift+C 复制工作流

### 2. 粘贴 JSON
将 JSON 内容粘贴到右侧的文本框中

### 3. 输入替换规则
在左侧文本框中输入替换规则，格式为：`节点号,字段名,新值`

示例：
```
22,url,#{image}
15,seed,42
8,text,hello world
20,strength,0.8
```

### 4. 验证与替换
- 点击"验证规则"验证语法（可选）
- 点击"执行替换"执行替换操作
- 查看下方日志了解替换详情

### 5. 导出结果
替换完成后，右侧的 JSON 会自动更新：
- 手动复制修改后的 JSON，粘贴回 ComfyUI
- 或保存为文件

## 规则格式详解

### 基本格式
```
节点号,输入字段名,替换值
```

### 参数说明
| 参数 | 说明 | 示例 |
|------|------|------|
| 节点号 | ComfyUI 工作流中节点的ID | 22, 15, 8 |
| 输入字段名 | 节点 inputs 对象中的字段名 | url, seed, text |
| 替换值 | 新的值，可以是任何字符串 | #{image}, 123456, hello |

### 常见字段

对于不同类型的节点，常见的输入字段包括：
- **ModelLoader**：model, ckpt_name
- **LoraLoader**：lora_name, strength_model, strength_clip
- **ClipTextEncode**：text, clip
- **LoadImage**：image, url（UI URL)
- **Sampler**：seed, steps, cfg, sampler_name, scheduler
- **VAEDecode**：vae, samples

## 注意事项

1. **节点号必须存在**：替换前确保节点号在 JSON 中存在
2. **字段名必须正确**：字段名区分大小写，必须与 JSON 中的字段名完全相同
3. **JSON 格式要求**：确保 JSON 是有效的格式，可用"验证 JSON"按钮检查
4. **多个规则**：可以一次性输入多个规则，每行一个
5. **日志查看**：替换日志会显示每个操作的详细信息，便于排查问题

## 常见场景

### 场景 1：替换随机种子
```
5,seed,12345
```

### 场景 2：替换图像 URL
```
3,url,https://example.com/image.png
10,url,#{image}
```

### 场景 3：替换提示词
```
6,text,一只可爱的小狗
7,text,高质量，4K，HDR
```

### 场景 4：替换多个参数
```
2,model,sd_xl_base_1.0.safetensors
3,url,#{image}
4,seed,999
5,text,beautiful landscape
```

## 故障排除

### 问题 1：替换日志显示节点不存在
- **原因**：节点号在 JSON 中不存在
- **解决**：检查节点号是否正确，可在 JSON 中搜索确认

### 问题 2：替换失败，字段不存在
- **原因**：字段名不正确或节点没有该字段
- **解决**：查看 JSON 结构，确认节点的 inputs 字段名

### 问题 3：JSON 格式错误
- **原因**：粘贴的 JSON 内容不完整或格式不正确
- **解决**：使用"验证 JSON"按钮检查，或重新复制 JSON

## 提示

- 使用"格式化 JSON"让 JSON 更易阅读
- 替换前建议备份原始 JSON
- 日志面板可查看完整的替换历史
- 支持一次性替换多个节点的多个字段
